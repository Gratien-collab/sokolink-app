# SokoLink

Base Expo / React Native de démonstration pour SokoLink.

## Contenu
- `App.js` : écran d'accueil et sélection parmi 52 marchés africains.
- `app.json` : identité Expo et icône Android.
- `eas.json` : profils EAS pour APK de test et Android App Bundle.
- `assets/sokolink-icon.png` : icône de l'application.

## Génération
Après installation des dépendances et liaison du projet à EAS :
`eas build --platform android --profile preview`

Ne lancez la compilation qu'après vérification du projet Expo et de son identifiant EAS.
